# fe3ds-forge 系统架构设计

`fe3ds-forge` 面向 3DS《火焰纹章》三部曲（FE13 觉醒 / FE14 if / FE15 回声），采用 **Rust + Tauri v2 + Vue 3 / TypeScript** 四层插件化架构，实现底层编解码与游戏数据结构彻底解耦。

## 四层分层模型

```text
+-------------------------------------------------------------------+
| 4. 表现与交互层 (src/ · Vue 3 + TypeScript + 原生 CSS 变量)        |
|    - Schema 驱动的通用可视化编辑页（自动生成滑块/表格/搜索/批量）  |
|    - 自定义视图插件槽（预留转职树、支援矩阵、地图站位等复杂组件）  |
+-------------------------------------------------------------------+
| 3. 桌面胶水与工作区层 (src-tauri/ · Tauri v2 IPC)                  |
|    - 非破坏性工程状态与差异记录 (.fe3dsproj)                       |
|    - 模拟器 mods 目录自动探测与一键写入                            |
+-------------------------------------------------------------------+
| 2. 声明式数据契约层 (schemas/<game>/*.json + core::schema)         |
|    - 零代码描述角色、职业、武器、道具、技能等二进制表结构          |
|    - 统一完成边界校验、加密字段映射、原生汉化译名关联              |
+-------------------------------------------------------------------+
| 1. 基础设施内核层 (crates/fe3ds-core · 纯 Rust，零 UI 依赖)        |
|    - lz11: LZ11 / LZ13 通用无损压缩与解压                          |
|    - bin_archive: IS 标准 .bin 容器解析与定长原地覆写              |
|    - cipher: 成长率双射置换表与密钥流加解密                        |
|    - message: RomFS/m UTF-16LE 文本档案解析                        |
|    - exefs_patcher: AOB 特征码扫描、ARM32 补丁、IPS/金手指导出     |
|    - exporter: LayeredFS 补丁包安全导出                            |
|    - [Phase 3] vfs / ctpk: 3DS/CIA 按需流式直读与立绘贴图解码      |
+-------------------------------------------------------------------+
